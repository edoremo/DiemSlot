# DIEMSlot

Applicazione desktop per la gestione delle **aule, dei docenti e delle prenotazioni** di un dipartimento universitario, sviluppata per il corso di Ingegneria del Software (Corso di Laurea in Ingegneria Informatica, DIEM – Università di Salerno).

L'applicazione è pensata per l'addetto di segreteria, che registra e consulta le prenotazioni per conto dei docenti.

## Funzionalità

- Gestione di aule e docenti (inserimento, modifica, cancellazione, ricerca)
- Ricerca delle aule disponibili in una data e fascia oraria
- Prenotazioni singole o ricorrenti (con cadenza settimanale)
- Controllo delle sovrapposizioni per aula e per docente
- Visualizzazione delle prenotazioni, filtrabili per aula o docente
- Salvataggio dei dati su file
